# 《逃学模拟器》第一版关卡设计 v0.1（策划思路）

> 范围：`CampusEscape` 第一版可玩原型。  
> 目标：从当前“教室切片”出发，用最小系统实现“躲视线 + 拿东西过关 + 两条出口”，让玩家第一次试玩就能感觉到“条条大路通校门”。  
> 依据：`doc/项目基础解释.md`、`doc/逃学模拟器_MVP框架_v0.2.md`、`doc/逃学模拟器_关卡设计_v0.1.md`。

---

## 0. 这一版的设计结论

第一版只做一条完整关卡链：**教室 → 三楼走廊 → 厕所检查点 / 教师办公室 → 楼梯 → 校门广场 → 正门或狗洞出口**。

两条通关路线：

| 路线 | 关键道具 | 通关方式 | 玩家感受 |
|---|---|---|---|
| A 正门线 | 请假条 | 拿请假条 → 门卫单点判定 → 正门离开 | “我是合法走的” |
| B 狗洞线 | 钳子 | 拿钳子 → 剪开狗洞铁丝网 → 离开学校 | “我把学校钻穿了” |

第一版核心动词只有两个：**躲** 和 **拿东西过关**。  
所有关卡都是这两个动词在不同校园空间里的变奏。

本版暂不落地：声音系统、动态作息、人流潮汐、摄像头、消防演练、伪证链、概率识破、翻墙、后门、混放学。这些内容保留为后续扩展槽位。

## 4. 每关详细设计

## L0 教室：观察与离座

### 如何抵达

开局就在本班教室，玩家坐在最后一排靠窗。

### 空间

```text
┌──────────────────────┐
│ 	黑板 / 讲台          │
│                      │
│ 课桌 课桌 课桌          │ 
│						│
│ 课桌 课桌 课桌
│
│ 课桌 课桌             
│						后门 
│
│   
└──────────────────────┘
```

### 威胁

数学老师背对黑板写字，周期性回头。第一版沿用现有代码逻辑：被看见后警觉增长，满 100 被抓。

### 通关方式

1. 玩家观察老师回头节奏。
2. 等老师转身写板书或擦黑板时离开座位。
3. 沿课桌之间低姿态移动到教室后门。
4. 通过后门进入 L1 三楼走廊。

### 失败与恢复

- 被老师看见：警觉上涨；满 100 后播放“罚站/拎去教导处”短演出。
- 恢复点：教室座位起点。
- 道具状态保留。第一版此处还没有道具，主要教学“看时机”。

### 设计意图

这是操作教学关。玩家学会三件事：第一人称移动、观察 NPC 朝向、等待安全窗口。  
当前代码里“走到黑板附近成功”的胜负点，在第一版策划中调整为“从后门离开教室”，与后续关卡链一致。

## L1 三楼走廊：核心潜行关

### 如何抵达

从教室后门进入。走廊东西向，东端是教师办公室，西端是楼梯口，中段有厕所门。

### 空间

```text
东端                                      西端
办公室门   宣传栏   垃圾桶   厕所门   消防栓   楼梯口
   │         │        │        │        │        │
└──────────────────────────────────────────────┘
      主任巡逻方向：东 → 西 → 东，周期约 40 秒
```

### 威胁

教导主任陈建国沿走廊往返巡逻：

- 视野：9m / 半角 35°。
- 走到宣传栏前停 3 秒看手机，这是玩家的稳定前进窗口。
- 看到玩家后警觉按站/蹲状态增长。
- 警觉满 100 → 被抓。

### 关键物件

| 物件 | 位置 | 作用 |
|---|---|---|
| 数学周测卷 | 走廊中段宣传栏夹缝 | 持有时可通过主任盘问 |
| 门框凹陷 | 走廊两侧 | 完全遮挡视线 |
| 垃圾桶 | 中段 | 蹲下后遮挡 |
| 拖把桶 + 警示牌 | 靠近厕所 | 遮挡视线 |
| 消防栓箱 | 靠西侧 | 遮挡视线 |

### 通关方式

玩家可以按两种风格通过：

**潜行流：**

1. 利用门框、垃圾桶、宣传栏、消防栓切断主任视线。
2. 主任在宣传栏看手机时快速推进一段。
3. 到西端楼梯口进入 L4。

**伪装流：**

1. 从宣传栏夹缝拿到试卷。
2. 正面遇到主任时触发盘问。
3. 手持试卷且面朝办公室方向，判定通过。
4. 通过后获得一段安全窗口，继续往办公室或楼梯移动。

### 盘问判定

```text
主任盘问：
if 玩家持有试卷 且 面朝办公室方向:
    放行
else:
    警觉 +30
    主任继续拦路
```

第一版概率固定 100%，避免引入随机失败。

### 失败与恢复

- 警觉满 100：被抓，传送到厕所检查点或走廊起点。
- 已拿到的试卷保留。
- 警觉清零，主任回到巡逻路线。

### 抵达下一关

- 去正门线：从东端办公室门进入 L3。
- 去狗洞线：从西端楼梯口进入 L4。
- 警觉偏高：先进 L2 厕所清零。

### 设计意图

这是整个第一版的核心。玩家在这里第一次完整体验“看视线 → 找掩体 → 拿道具 → 编理由”的循环。

## L2 厕所检查点：安全屋与节奏低谷

### 如何抵达

从走廊中段厕所门进入。

### 空间

```text
┌────────────┐
│ 洗手台      │
│            │
│ 隔间1 隔间2 │
└────────────┘
```

### 威胁

第一版只保留轻威胁：主任巡逻到厕所门口时会扫一眼走廊。进入隔间后视线被遮挡。  
随机巡查、坏门、换装等愿景内容留到后续版本。

### 通关方式

1. 走到洗手台按交互。
2. 警觉清零。
3. 玩家获得短暂停顿，再从厕所门回到走廊。

### 失败与恢复

厕所本身是恢复点，被抓后也会回到这里。  
若玩家在洗手时警觉增长，先躲进隔间等待视线离开。

### 抵达下一关

出厕所后按玩家目标选择：

- 向东：教师办公室。
- 向西：楼梯间。

### 设计意图

给玩家一个明确的低压节点。走廊的高压之后需要一次喘息，否则后续楼梯和出口判定会显得连续惩罚。

---

## L3 教师办公室：请假条取物关

### 如何抵达

从三楼走廊东端办公室门进入。

### 空间

```text
┌──────────────────────┐
│ 工位   工位   工位     │
│ 工位   工位   工位     │
│       [请假条桌子]    │
│ 门缝观察位             │
└──────────────────────┘
```

### 威胁

办公室内有一名批作业老师。第一版只用视线判定：

- 老师低头批作业：可进入并移动。
- 老师抬头看向门口：玩家需要停在掩体后或退回门框。
- 门缝观察位可提前看到老师朝向。

声音系统暂不进入第一版，因此打印机、饮水机、电话铃只作为场景装饰和视线掩体。

### 关键物件

| 物件 | 位置 | 作用 |
|---|---|---|
| 空白请假条 | 靠门工位桌面 | 正门线钥匙 |
| 办公桌 | 工位之间 | 视线遮挡 |
| 门框 | 入口 | 观察与撤退点 |

### 通关方式

1. 从门缝观察老师朝向。
2. 等老师低头批作业时进入。
3. 走到靠门工位拿请假条。
4. 原路退回走廊。

### 失败与恢复

- 被老师看见并盘问：没有合适理由时警觉 +30。
- 警觉满 100：被抓，传送到厕所检查点。
- 请假条在取得后永久保留。

### 抵达下一关

拿着请假条回到走廊：

```text
办公室 → 三楼走廊 → 厕所检查点（可选）→ 楼梯间 → 校门广场
```

### 设计意图

这关负责把“钥匙”做成世界里的物件，而不是任务奖励。玩家看见桌上的请假条，就会理解“这张纸是离开学校的合法理由”。

## L4 楼梯间：分段视线关

### 如何抵达

从三楼走廊西端楼梯口进入。

### 空间

```text
[3F 平台]
   │
   ├── 转角平台（视线观察点）
   │
[2F 平台]
   │
   └── 一楼出口 → 校门广场
```

### 威胁

第一版不加入人流潮汐。改用“分段视线”表达楼梯压力：

- 主任有时会从三楼走廊口扫向楼梯。
- 转角平台是观察点。
- 玩家在平台上可看到上层入口，再决定下楼时机。

### 通关方式

1. 到转角平台停下。
2. 观察三楼入口是否空档。
3. 趁主任转身或远离楼梯口时跑下两层。
4. 抵达一楼出口，进入 L5 校门广场。

### 失败与恢复

- 被主任发现：警觉增长。
- 警觉过高时退回厕所检查点；已到一楼后则回到楼梯口检查点。
- 道具保留。

### 抵达下一关

一楼楼梯出口直接进入校门广场。

### 设计意图

 corridor 是水平视线压力，楼梯是垂直分段压力。空间形状变化了，但机制仍是视线与时机，符合“一个机制 + 多种包装”的 MVP 原则。

---

## L5 校门广场：路线分歧关

### 如何抵达

从楼梯间一楼出口进入。

### 空间

```text
                 ┌──────────────┐
                 │ 正门 / 门卫室 │
                 └──────┬───────┘
                        │
器材室 ─────── 广场主路 ─────── 后墙狗洞
   │                                  ↑
   └────────────── 钳子 ──────────────┘
```

### 威胁

- 门卫老张守在正门，只做单点盘问。
- 主任视野仍可作为外部压力：如果玩家在广场停留太久，警觉上涨更快。
- 广场没有复杂 NPC 分布，第一版重点是“选择路线”。

### 关键选择

| 选择 | 需要的钥匙 | 后续关卡 | 难度 |
|---|---|---|---|
| 去正门 | 请假条 | L6 正门 | ★ |
| 去器材室 | 无 | L7 器材室 → L8 狗洞 | ★★★ |

### 通关方式

玩家到达广场后即可视为本关完成，接下来进入任一出口线。

### 失败与恢复

广场本身没有独立失败。警觉满则传送到楼梯口检查点。

### 抵达下一关

- 有请假条：走向正门。
- 想走硬核线：先去器材室拿钳子，再去后墙狗洞。
- 没有钥匙也可以探索，门卫和狗洞会给出明确提示。

### 设计意图

这是“条条大路通校门”被玩家第一次直观看见的地方。正门和狗洞都在同一视野范围内，玩家会自然形成“换一条路试试”的想法。

## L6 正门：请假条出口

### 如何抵达

从校门广场中央走向门卫室。

### 空间

```text
广场主路 → 登记本 → 门卫老张 → 正门铁门 → 校外
```

### 威胁

门卫老张单点盘问。第一版不做三问交叉验证，只认请假条。

### 通关方式

```text
门卫盘问：
if 玩家持有请假条:
    放行 → 通关 A：合法逃学
else:
    警觉 +30
    门卫继续拦路
```

### 失败与恢复

- 没有请假条：门卫拦路，警觉 +30，玩家可退回广场换狗洞线。
- 警觉满：传送到楼梯口检查点，请假条状态保留。

### 抵达下一关

出口，进入通关结算。

### 设计意图

这是最简单、最像“正当离校”的结局。它给新手玩家一条清晰低难度通关路径。

---

## L7 器材室：钳子取物关

### 如何抵达

从校门广场右侧进入器材室。

### 空间

```text
┌──────────────────────┐
│ 篮球架   垫子堆       │
│                      │
│ 工具箱 [钳子]  器材柜 │
└──────────────────────┘
```

### 威胁

器材室第一版没有常驻巡逻 NPC。压力来自路线选择：玩家离开广场越久，广场方向的主任越可能靠近。

### 关键物件

| 物件 | 作用 |
|---|---|
| 工具箱 | 钳子所在位置 |
| 篮球架 / 垫子堆 | 视线遮挡，强化器材室空间感 |
| 器材柜 | 环境线索，暗示后勤工具来源 |

### 通关方式

1. 进入器材室。
2. 在工具箱旁互动取得钳子。
3. 从侧门或原路离开，前往后墙狗洞。

### 失败与恢复

本关没有独立失败。若被广场方向发现，警觉增长，玩家可退回器材室躲视线。

### 抵达下一关

```text
器材室 → 后墙狗洞
```

### 设计意图

狗洞线需要玩家主动探索边角空间。器材室是把“钳子”放进校园逻辑里的位置，不需要凭空刷新道具。

---

## L8 后墙狗洞：硬核出口

### 如何抵达

从器材室旁的后墙通道进入。

### 空间

```text
器材室侧门 → 垃圾房 → 后墙 → 狗洞铁丝网 → 校外
```

### 威胁

- 后墙区域靠近广场，停留过久会累积警觉。
- 没有钳子时，铁丝网只给提示，不直接触发失败。

### 通关方式

```text
狗洞判定：
if 玩家持有钳子:
    剪开铁丝网 → 通关 B：飞檐走壁
else:
    提示“狗洞被铁丝网挡住了，需要工具”
```

第一版成功率按 100% 固定。后续可加入“无垫脚箱 60% 成功”的赌点。

### 失败与恢复

- 没有钳子：继续探索器材室。
- 被看见导致警觉满：传送到楼梯口检查点，钳子保留。
- 道具和出口状态保留。

### 抵达下一关

出口，进入通关结算。

### 设计意图

这是给主动探索玩家的硬核奖励。它绕开门卫，证明玩家把学校空间本身当成了路。

---

## 5. 两条完整通关路线

## 路线 A：正门请假条线

```text
教室
 → 等老师回头，从后门离开
 → 三楼走廊
 → 拿试卷，躲主任；遇盘问时持试卷面朝办公室方向通过
 → 教师办公室
 → 等老师低头，拿请假条
 → 厕所检查点（可选，清零警觉）
 → 楼梯间
 → 观察转角视线，下到一楼
 → 校门广场
 → 门卫出示请假条
 → 正门通关
```

### 为什么成立

- 试卷解决走廊里的主任盘问。
- 请假条解决正门门卫盘问。
- 厕所给玩家一次降压，避免连续高压导致烦躁。
- 正门难度低，适合首通玩家。

---

## 路线 B：狗洞钳子线

```text
教室
 → 从后门离开
 → 三楼走廊
 → 用掩体绕开主任；试卷可选
 → 楼梯间
 → 下到一楼
 → 校门广场
 → 右侧器材室
 → 工具箱拿钳子
 → 后墙狗洞
 → 剪开铁丝网
 → 狗洞通关
```

### 为什么成立

- 狗洞不认请假条，只认钳子。
- 钳子放在器材室，玩家通过空间探索自然获得。
- 狗洞绕开门卫，给“不想编理由”的玩家一个物理路线。
- 难度高于正门，但奖励是更强的“我钻穿了学校”的感觉。

---

## 6. 关键遭遇卡

## E1 主任视线巡逻

| 项 | 内容 |
|---|---|
| 所在关卡 | L1 三楼走廊、L4 楼梯间外部压力 |
| 类型 | 潜行 / 时机 |
| 胜利 | 未被发现，或警觉未到 100 前抵达安全点 |
| 失败 | 警觉满，被抓 |
| 恢复 | 传送检查点，道具保留，警觉清零 |
| 预期策略 | 看巡逻方向，利用掩体分段推进 |
| 替代策略 | 拿试卷后正面通过盘问 |
| 机制 | 距离、角度、掩体遮挡、警觉涨落 |
| 设计检查 | 主任停手机的 3 秒窗口必须足够玩家推进一个掩体间距 |

## E2 主任试卷盘问

| 项 | 内容 |
|---|---|
| 所在关卡 | L1 三楼走廊 |

| 胜利 | 持试卷且面朝办公室方向，放行 |
| 失败 | 警觉 +30，主任继续拦路 |
| 恢复 | 躲进掩体降警觉，或换路线 |
| 预期策略 | 先拿试卷，再正面应对 |
| 替代策略 | 完全绕开主任，不触发盘问 |
| 设计检查 | 试卷用途必须通过一次提示或玩家尝试自然表达 |

| 预期策略 | 门缝观察后进入 |

## 7. 节奏曲线

```text
强度
10 │                         ████ 出口判定
 8 │          ████           ██
 6 │      ████    ██     ████
 4 │  ████         ████
 2 │██                 ██
 0 └──────────────────────────────────
   教室  走廊  厕所  办公室  楼梯  广场  出口
```

目标节奏：

1. 教室低强度教学。
2. 走廊第一座高峰，教“躲与编”。
3. 厕所低压，清零警觉。
4. 办公室取物，安静但紧张。
5. 楼梯短峰，考验视线时机。
6. 广场选择，玩家主动性达到高点。
7. 出口判定作为终局高峰。

## 9. 无障碍与可读性

- 可交互物件统一使用粉笔高亮描边，不只依赖颜色。
- 警觉值同时用数字条、屏幕边缘粉笔划痕和角色呼吸声后续槽位表达；第一版至少保留视觉条。
- 盘问提示使用大字号文本，保证第一人称近距离可读。
- 关键路线不依赖快速反应；主任停顿窗口至少 3 秒。
- 狗洞、正门、办公室门口都提供文字提示，避免玩家找不到目标。
- 蹲下与站立状态有 HUD 文字提示。

## 10. 第一版验收标准

| 验收项 | 标准 |
|---|---|
| 核心循环 | 玩家能用“躲视线 + 拿东西”完成至少一条路线 |
| 多路线 | 首通玩家能发现正门和狗洞两条出口 |
| 钥匙系统 | 试卷、请假条、钳子都有单一明确用途 |
| 警觉系统 | 被看见上涨、躲掩体下降、盘问失败一次性上涨 |
| 失败体验 | 被抓后传送检查点，道具保留，警觉清零 |
| 时长 | 首次通关 8–12 分钟 |
| 可读性 | 玩家在走廊、办公室、广场不长期迷路 |
| 复玩动机 | 玩家通关一条路线后想尝试另一条 |

## 11. 开发落地顺序

1. **改教室胜负点**：从“黑板附近成功”改为“后门进入走廊”。
2. **搭三楼走廊白模**：40m 走廊、掩体、试卷、主任巡逻。
3. **接入警觉值**：站立/蹲下/掩体/盘问失败四条规则。
4. **加厕所检查点**：洗手清零警觉，被抓传送。
5. **加教师办公室**：请假条取物，老师背身窗口。
6. **加楼梯间**：转角视线观察，一楼出口。
7. **加校门广场**：正门与狗洞两个方向可视化。
8. **加门卫盘问与狗洞判定**：两条通关路线闭合。
9. **补器材室和钳子**：狗洞线成立。
10. **试玩调参**：主任视距、巡逻速度、警觉涨落、掩体间距。

## 13. 一句话给程序的实现边界

第一版只需要实现：**一个玩家、一个巡逻主任、一个门卫触发器、三个 bool 道具、两个出口、两个检查点、一条警觉值**。其余内容都能用场景物件和文案包装出来。
