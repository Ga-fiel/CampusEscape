# L0 教室：观察与离座（第一关详细设计 v0.3·代码对齐版）

> 关卡定位：第一关是操作与规则教学关。玩家在座位上醒来，学会观察老师朝向、控制站立/蹲下、避开碰撞噪声，并在合适时机从后门离开教室。  
> 核心动词：**看时机 → 控身位 → 安静离座**。  
> 失败口径：老师看见暴露在视线中的玩家，或碰撞噪声把怀疑度推到 100%，播放实时演出后进入失败界面。  
> 术语说明：本文的“怀疑度”等同全局规则里的“警觉值”，是第一关的具象表现。  
> 本文以 `src/level.js`、`src/main.js`、`src/teacher.js` 的当前参数为灰盒基线；“当前切片”和“目标规则”分开描述，避免把尚未实现的功能当成已有能力。

---

## 1. 关卡目标与体验

### 1.1 玩家在这一关学会什么

1. 老师不是一直看着玩家：**背对黑板写字时可以移动，回头时不能暴露**。
2. 站立移动快但风险高；蹲下慢，却能借助桌体降低暴露概率。
3. 蹲下不等于绝对安全：碰撞桌椅同样会发出动静并引来老师回头。
4. 教室内有可观察的安全窗口：老师写板书、擦黑板、转身离开讲台巡逻。
5. 第一关的目标不是“走到黑板”，而是**从后墙偏右的粉笔画门离开教室，进入三楼走廊**。

### 1.2 情绪曲线

```text
在座位平静醒来 → 观察老师写板书的节奏（安全）
              → 第一次回头或碰撞噪声（紧张）
              → 借桌椅遮挡向后门推进（取舍）
              → 每 45 秒巡逻一圈（压力峰值）
              → 抓到空档推门离开（释放）
```

### 1.3 时长与难度

| 项目 | 取值 |
|---|---:|
| 目标时长 | 60–120 秒 |
| 难度定位 | 入门，允许 2–3 次失败后理解规则 |
| 主要教学 | 观察、站蹲切换、避免碰撞噪声、利用桌椅遮挡 |
| 第一关道具 | 无 |
| 第一关分支 | 无强制分支；后门为唯一通关出口 |

## 2. 当前代码基线与目标差距

### 2.1 已有能力

- 第一人称鼠标观察、`WASD` 移动、指针锁定。
- 固定教室、黑板、讲台、15 张课桌和后墙粉笔画门。
- 墙体、讲台、桌面的 XZ 平面 AABB 碰撞；玩家半径 `0.35m`。
- 老师沿四个巡逻点移动，速度 `1.8m/s`。
- 老师具有半角 `35°`、距离 `9m` 的视锥检测（v0.4 已改为视距 `26m`，见 3.3）。
- 被发现后的失败提示、旧胜利提示，以及结束后的 `R` 重开。

| 目标规则 | 当前代码状态 | 修改位置 |

| 从后门推门通关 | 当前以 `z < -9.8`，即摸到黑板墙判胜 | `src/main.js` 胜利区域与 `E` 交互 |

| 视线被桌椅遮挡 | 当前仅判断距离和角度，没有遮挡射线 | `src/teacher.js` 增加遮挡检测 |
| 怀疑度、碰撞噪声 | 当前视锥看到一次就直接失败 | `src/main.js` 管理怀疑度与碰撞事件 |

## 3. 机制玩法

### 3.1 玩家能力

| 动作 | 目标规则 | 代码对齐参数 / 设计意图 |
|---|---|---|
| 站立行走 | 默认移动方式 | 沿用 `4.2m/s`，眼高 `1.6m`，用于安全窗口快速推进 |
| 蹲下移动 | 速度为站立的 `1/10` | `0.42m/s`，建议眼高 `0.85m`；形成“慢但低姿态”的取舍 |
| 站蹲切换 | `Shift` 按住或切换，第一版选一种并全程一致 | 推荐按住 `Shift` 蹲行，减少新手记忆成本 |
| 跳跃 | 保留为次要能力，不作为主路线必需 | 当前未实现；可最后加入，不阻塞第一关验证 |
| 碰撞桌椅 | 产生动静：怀疑度 `+35%`，强制老师回头 | 同一次持续接触只结算一次，建议冷却 `0.8s` |
| 静止且未被发现 | 怀疑度每秒 `−1%` | 站立、蹲下都衰减；最低为 0 |
| 被无遮挡视线看到 | 怀疑度直接 `100%` | 进入失败演出，保留第一版强规则 |
| 推门 | 靠近后门按 `E` | 本关唯一胜利交互 |

### 3.2 怀疑度规则表

| 事件 | 数值变化 | 老师反应 |
|---|---:|---|
| 老师回头或巡逻时，无遮挡看到玩家 | 直接 `100%` | 锁定输入并进入失败演出 |
| 撞到课桌、椅子或讲台 | `+35%` | 中断当前动作，回头观察玩家方向 |
| 怀疑度因碰撞达到 `100%` | 保持 `100%` | 进入失败演出 |
| 蹲下且静止，未被看到 | `−1% / 秒` | 无 |
| 站立且静止，未被看到 | `−1% / 秒` | 无 |
| 移动但未碰撞、未被看到 | 不额外增长 | 无 |
| 玩家处于有效桌体遮挡后 | 不增长 | 老师按原行为继续 |

### 3.3 老师行为状态机

老师采用“讲台授课”与“周期巡逻”叠加，而不是持续绕圈。

#### A. 写板书

- 初始驻点建议为 `(0, 0, -8.2)`，位于讲台南侧，面向黑板，即朝向 `-Z`。
- 单手持书，另一只手做写粉笔字动作；黑板内容为勾股定理。
- 每次背身持续随机 `3–6s`。
- 回头前给出至少 `0.4s` 预兆：粉笔动作停止、书本微沉、肩膀先转，同时出现 UI 视线图标。
- 回头后做一次视线检测；看到无遮挡玩家即失败，未看到则停留约 `0.8s` 后转回黑板。

#### B. 碰撞诱发的回头

- 玩家碰撞桌椅时，老师立即结束当前板书动作并回头。
- 该回头与随机回头共用判定和预兆，但预兆可缩短到 `0.25s`，保证“碰撞会引来注意”的因果清晰。
- 若玩家已经在桌后蹲好，老师看不到人，怀疑度保留碰撞增加的数值，不直接失败。

#### C. 每 45 秒下讲台巡逻

- 从进入本关开始计时，每 `45s` 触发一次；碰撞回头不重置该计时。
- 沿用当前代码的巡逻坐标，顺序为：
  - `(1) (5, 0, -6)`：前排右侧；
  - `(2) (5, 0, 6)`：后排右侧；
  - `(3) (-5, 0, 6)`：后排左侧；
  - `(4) (-5, 0, -6)`：前排左侧；
  - 随后返回讲台 `(0, 0, -8.2)`。
- 巡逻速度沿用 `1.8m/s`，视锥沿用同一套参数（半角 `32°`→远处收窄到 `24°`、视距 `26m`），但必须加入桌椅遮挡检测。
- 巡逻期间仍需正常写板书以外的行走动画，避免“滑行木偶感”。
- 若巡逻开始时正在进行碰撞回头，先完成回头判定，再继续巡逻，不叠出两次失败。

### 3.4 视线与遮挡口径

- 老师视点建议取 `(老师位置.x, 1.75, 老师位置.z)`。
- 玩家站姿检测点取眼高附近 `1.6m`，蹲姿检测点取 `0.85m`。
- 仅当“距离小于视距 + 位于视锥内 + 老师与玩家检测点之间无桌体/讲台遮挡”同时成立，才判为看到。
- 桌腿不参与遮挡；桌面、讲台和墙体参与遮挡，与碰撞数据尽量复用。
- 当前课桌桌面高 `0.95m`，因此站姿通常高于桌体，蹲姿在靠近桌后时更可能获得遮挡；不能简单规定“蹲下即隐身”。
- 第一版只检测一个中心点即可，后续如需减少“半个身体露在外面却没被发现”的争议，再增加肩部采样点。

#### 3.4.1 视锥参数（v0.4）

原先是半角 `35°`、视距 `9m`，从讲台只能看到约一半教室，后排是完全安全的，玩家靠到 `z > 1` 就无敌。改为：

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 视距 | `26m` | 讲台 `z=-8.2` 到后墙 `z=11` 是 `19.2m`，留 35% 余量 |
| 水平半角 | 近处 `32°`，按 `32° - 8° × (d/26)` 收到远处 `24°` | 近处张得开，远处收窄但不出现正前方死角 |
| 垂直半角 | `±40°` | 单独判仰俯角，避免近处贴脸课桌不进入锥形 |
| 遮挡 | 3D 线段与 `occluders` AABB 求交 | 蹲在桌后仍然看不见，视野再长也穿不过桌面 |

效果（讲台回头看，站立眼高 1.6）：

- 中轴 `z=-7.2 → 9.3` 全程可见，最后两排不再有安全区；
- 后墙一排 `x=-7.4 → 7.0` 全部可见；
- 最后一排蹲姿（眼高 `0.85`）也落在锥形内，靠的是**课桌遮挡**而不是距离活着；
- 盲区来自**两侧**的锥形边界和桌椅遮挡，不是“正前方看不到”。

实际保护玩家的仍然只有三条：蹲在桌后、绕开锥形两侧、以及老师回头前 `0.4s` 的预兆。

### 3.5 失败流程

1. 怀疑度达到 `100%` 后立即锁定移动和姿态输入。
2. 不先弹对话框；老师转向玩家并实时走来。
3. 老师移动建议使用简易过道路径点，速度约 `3.0m/s`，不得穿过课桌或讲台。
4. 老师停在玩家前方约 `1.2m` 处，面对玩家。
5. 弹出粉笔风对话框：
   - “你在干什么！”
   - “为什么离开座位！”
6. 进入失败界面；按 `R` 从座位起点重开。
7. 重开时清空怀疑度、碰撞冷却、老师状态与巡逻计时，避免继承上一局进度。

### 3.6 通关流程

1. 玩家在第二排左侧座位醒来。
2. 观察老师背身写板书的节奏。
3. 等老师再次背过身去，离开座位。
4. 沿课桌间过道向教室后方低姿态移动，避免碰撞。
5. 到达后墙偏右的粉笔画门，确认老师未看向自己。
6. 按 `E` 推门，显示通关提示；第二关未完成时直接结束切片，不假装已经切到完整走廊关卡。

### 4.1 坐标与尺寸

| 黑板 | 宽 `9m`，中心约在 `(0, 2.3, -10.82)` | 北墙视觉中心 |

### 4.2 当前可玩课桌阵列

当前代码为 **3 列 × 5 排 = 15 张桌**，不是旧文档的 48 座。第一关先以这 15 张桌验证玩法，美术扩容不阻塞切片。

- 列中心：`X = -4.6、0、4.6`。
- 排中心：`Z = -5.5、-2.5、0.5、3.5、6.5`。
- 桌面：`1.8m × 0.9m`，高 `0.95m`。
- 玩家出生点建议：`(-4.6, 1.6, -1.55)`，即第二排左侧桌子的南侧，初始 `yaw = 0`，面向黑板。
- 当前只有桌面进入碰撞列表；目标版本中椅背、椅子也必须参与噪声碰撞，否则视觉与手感不一致。

当前灰盒的通行余量：

| 通道 | 几何净距（未扣玩家直径） | 结论 |
|---|---:|---|
| 相邻课桌列之间 | `4.6 - 1.8 = 2.8m` | 灰盒非常宽，足够教学与巡逻 |
| 相邻课桌排之间 | `3.0 - 0.9 = 2.1m` | 可横向换列，不存在必然堵点 |
| 左侧桌到左墙 | 约 `2.5m` | 玩家可沿左侧向后撤退 |
| 最后一排桌面到后门区域 | 约 `3.85m` | 提供出口前观察与等待空间 |

> 这是一套宽松的教学灰盒，不冒充真实拥挤教室。若后续扩为 6 排 × 8 列，必须重新验证过道净宽、老师巡逻和蹲行遮挡，不能只把桌子数量加密。

### 4.5 课桌、椅子与同学表现

- 每张桌子配一把椅子；椅背当前在桌体北侧 `z - 0.39`，美术调整时不得改变主通道净宽。
- 桌面书本数量、开合状态、摆放角度可随机，但不改变碰撞体积。
- 同学可做趴着睡觉、抬头听课、低头记笔记的轻微 idle 动画，不参与发现判定、不举报。
- 椅子被碰到时发出噪声，可被推开约 `0.1m`；不能弹飞、翻转、穿墙或堵死唯一主通道。
- 桌子本体保持稳固，只给轻微晃动反馈。
- 同学、书本和椅子物理属于表现层增强，优先级低于站蹲、遮挡、怀疑度和出口流程。

## 5. 遭遇设计

### 5.1 遭遇 A：讲台回头

| 项目 | 内容 |
|---|---|
| 玩家证明什么 | 能读懂老师朝向，知道“背身可以移动，回头前应停下并寻找桌体遮挡” |
| 成功条件 | 回头瞬间不在无遮挡视线内 |
| 失败条件 | 站姿暴露，或蹲姿位置并没有形成真实遮挡 |
| 失败反馈 | 实时演出：老师走近 → 对话 → 失败界面 |
| 可重复方式 | `R` 重开，板书间隔重新随机 |

### 5.2 遭遇 B：碰撞噪声

| 项目 | 内容 |
|---|---|
| 玩家证明什么 | 蹲行也要规划路线，不能贴桌角硬挤 |
| 成功条件 | 沿过道移动，绕开椅背和桌角 |
| 失败条件 | 连续碰撞使怀疑度达到 100%，或碰撞回头时仍暴露 |
| 设计价值 | 让“慢”不等于“绝对安全”，同时保留一次失误后的补救机会 |

### 5.3 遭遇 C：45 秒巡逻

| 项目 | 内容 |
|---|---|
| 玩家证明什么 | 能综合应用遮挡、观察和路线选择 |
| 成功条件 | 避开巡逻视锥，利用桌体遮住老师到玩家的视线 |
| 失败条件 | 暴露在巡逻路线前方且无遮挡 |
| 节奏作用 | 本关最大压力峰值，也是推进到后门前的综合考验 |

## 6. 路线与节奏

### 6.1 主路线

```text
第二排左侧醒来 → 面向黑板观察 → 等老师背身
→ 从座位南侧退出 → 进入左侧或中央纵向过道
→ 沿 +Z 方向逐排后撤 → 在最后一排后方短暂观察
→ 老师背身或巡逻远离粉笔画门 → 走到后墙偏右 → [E] 推门
```

玩家可以在列间和排间换路，但第一关不设置必须理解的岔路，也不设置额外出出口。

### 6.2 节奏三段

1. **引入段（安全）**：醒来、看黑板、看老师背影；输入提示出现，第一次回头前留出观察时间。
2. **测试段（紧张）**：第一次 `3–6s` 回头；玩家学会停住、蹲下或躲到桌后。
3. **变化段（峰值）**：`45s` 巡逻；玩家必须结合桌椅遮挡和后撤路线抵达后门。

### 6.3 设计约束

- 不用“传送到终点”或冻结老师来冒充正常路线验收。
- 老师回头必须有动作预兆和 UI 提示，不能只靠随机数突然判负。
- 主路径应允许蹲行通过，椅子受控位移不得永久堵死通道。
- 巡逻路线和视线判定使用同一套实际场景数据；桌子视觉存在却没有遮挡时，应修实现而不是让玩家背隐藏规则。
- 失败重开必须足够快，不重复播不可跳过的长演出。

## 7. UI 细节

### 7.1 开场输入提示

进入游戏后前 8 秒，在画面左下角淡入：

```text
WASD 移动    鼠标观察
按住 Shift 蹲下    E 推门
目标：别被看到，从后门离开教室
```

8 秒后自动淡出；玩家按下对应按键后，该项提示可提前消失。跳跃未加入前不显示 `Space` 提示。

### 7.2 怀疑度显示

- 位置：准星下方偏右，细长条。
- 怀疑度为 0 时半透明隐藏；大于 0 时显示，3 秒无变化后淡出。
- 怀疑度上升时条体变粗并轻微抖动。
- 条体旁同时显示 `0–100%` 数字，不只靠颜色表达危险。
- 满 `100%` 时画面边缘出现红色压迫感，随后进入失败演出。

### 7.3 状态提示

| 状态 | UI 表现 |
|---|---|
| 蹲下 | 左下角显示“蹲行中”小图标与文字 |
| 碰撞桌椅 | 准星附近短暂出现“嘈杂！”文字 + 怀疑度条跳动 |
| 老师回头预兆 | 准星上方出现短暂视线图标 |
| 靠近后门但不满足交互距离 | 后门保留“出口”文字标签 |
| 进入后门交互区 | 显示 `[E] 推门离开教室` |
| 怀疑度达到 100% | 锁定输入，隐藏普通操作提示，进入失败演出 |

### 7.4 失败对话框

```text
┌──────────────────────────┐
│ 数学老师：               │
│ “你在干什么！”            │
│ “为什么离开座位！”        │
│                          │
│ [R] 重来                 │
└──────────────────────────┘
```

### 7.5 通关提示

推门后显示：

```text
离开教室
下一区域：三楼走廊（待制作）
```

提示保留 2 秒；当前切片随后停在通关界面，可按 `R` 重玩。

## 8. 环境叙事与美术表现

### 8.1 黑板内容

- 主题：初中勾股定理。
- 包含 `a² + b² = c²`、直角三角形辅助图、两三步推导草稿、少量擦痕与未擦净数字。
- 目标是让“老师正在上课”一眼成立，并帮助玩家理解老师背身的安全窗口。

### 8.2 粉笔火柴人老师

- 风格参考：`逃学模拟器第一关卡详细设计.assets/image-20261125205110487.png`。
- 保留当前代码的粉笔线条角色基础，补充：单手持书、写板书、回头预兆、双腿行走、走到玩家面前的压迫感。
- 动画不能只改变模型朝向：写板书、回头、巡逻三种状态必须在轮廓上可区分。

### 8.3 同学与桌面叙事

- 睡觉同学丰富课堂生活感，同时暗示“别人不会帮你”。
- 记笔记同学提供正常课堂状态，衬托玩家离群的紧张。
- 随机书本只改变外观，不改变桌面 AABB，避免视觉与实际玩法不一致。

## 9. 无障碍与可读性

- 老师回头同时具有动作预兆和 UI 视线提示，不只靠声音或颜色。
- 怀疑度同时提供条形、数字和文字反馈。
- 失败对话使用大字号和深色描边，保证在粉笔背景上可读。
- 普通回头至少提供 `0.4s` 反应窗口；碰撞诱发回头至少 `0.25s`。
- `R` 重开全局可用，包括正常游玩、失败演出和通关界面。
- 后门使用“出口”文字标签；若增加前门，则用“前门：锁”明确区分。

## 10. 实现备注

### 10.1 第一关不实现

- 道具系统；
- 盘问分支；
- 多出口选择；
- 同学举报；
- 复杂动态寻路与全教室导航系统；
- 真实视频过场；
- 完整三楼走廊关卡。

### 10.2 推荐实现顺序

1. **修正空间目标**：座位出生点、后门胜利区域、`E` 交互，移除“摸到黑板判胜”。
2. **补齐玩家规则**：站蹲、眼高、速度、全局 `R`、碰撞事件与冷却。
3. **改造老师状态机**：讲台写板书、`3–6s` 回头、预兆、`45s` 巡逻。
4. **补齐判定**：怀疑度、桌体遮挡、碰撞诱发回头。
5. **完成反馈闭环**：失败走近演出、对话、怀疑度条、状态提示、通关提示。
6. **增加表现**：书本、同学、黑板推导、持书与行走动画。
7. **按正常路线实测**：分别验证站姿速通、蹲行慢通、碰撞补救和巡逻期间通关。

### 10.3 最小重开状态

重开至少恢复：

- 玩家位置 `(-4.6, 1.6, -1.55)`、`yaw = 0`、`pitch = 0`、站立姿态；
- 怀疑度 `0`、碰撞冷却 `0`、所有临时 UI；
- 老师位置 `(0, 0, -8.2)`、朝向黑板、写板书状态；
- 下一次随机回头计时与 `45s` 巡逻计时；
- 椅子等可动物体的初始位置。

## 11. 验收标准

### 11.1 空间与移动

- [ ] 玩家出生在第二排左侧座位旁 `(-4.6, 1.6, -1.55)`，面向黑板。
- [ ] 教室使用当前 `16m × 22m` 灰盒与 3 列 × 5 排课桌，主通道无必然堵点。
- [ ] 玩家可站立、按住 `Shift` 蹲下；蹲行速度约 `0.42m/s`，眼高明显下降。
- [ ] 从座位到后门可以仅靠正常行走/蹲行完成，不需要跳跃或穿模。

### 11.2 老师与怀疑度

- [ ] 老师初始在讲台南侧背身写板书，并随机 `3–6s` 回头。
- [ ] 回头前有可读动作与 UI 预兆。
- [ ] 老师无遮挡看到玩家时，怀疑度按 `100%` 处理。
- [ ] 桌体位于老师和玩家之间时能按实际高度遮挡视线，蹲下不是无条件隐身。
- [ ] 碰到桌椅或讲台时怀疑度 `+35%` 并触发一次回头；持续接触不会每帧累加。
- [ ] 未被发现时，静止状态下怀疑度每秒 `−1%`。
- [ ] 每 `45s` 触发一次巡逻，路线为 `(1)→(2)→(3)→(4)→讲台`。
- [ ] 怀疑度达到 `100%` 后，老师不穿桌地实时走到玩家面前，再弹出指定对话。

### 11.3 出口、UI 与重开

- [ ] 后门是唯一通关出口；只有进入后门交互区并按 `E` 才判胜。
- [ ] 摸到黑板或前墙不再判胜。
- [ ] 当前切片通关后明确显示“三楼走廊（待制作）”。
- [ ] UI 同时提供图形与文字反馈，关键提示不只依赖颜色。
- [ ] `R` 在正常游玩、失败和通关状态均可从座位起点重开。
- [ ] 重开后老师状态、怀疑度、巡逻计时和可动物体全部复位。

### 11.4 表现层（核心玩法通过后验收）

- [ ] 黑板勾股定理、桌面书本、同学 idle、老师持书和行走动作可见。
- [ ] 美术变化不改变已验证的通行净宽与遮挡结果。

## 12. 待确认参数

| 项目 | 当前建议值 | 待确认内容 |
|---|---:|---|
| 蹲姿眼高 | `0.85m` | 与 `0.95m` 桌面形成的遮挡是否直观 |
| 蹲行速度 | `0.42m/s` | 全程蹲行是否过慢，是否应提高到站立的 `1/5` |

| 普通回头预兆 | `0.4s` | 低帧率下是否仍可读 |
| 碰撞回头预兆 | `0.25s` | 是否既保留惩罚感又允许补救 |
| 碰撞怀疑度 | `+35%` | 三次碰撞失败的惩罚是否合适 |
| 碰撞冷却 | `0.8s` | 是否能避免一次擦碰被重复结算 |

| 48 座扩容 | 不在灰盒首轮执行 | 扩容后重新验证尺寸、巡逻和遮挡 |
