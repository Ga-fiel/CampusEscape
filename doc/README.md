## 运行

```bash
python serve.py 8931
```

然后打开 <http://127.0.0.1:8931/>。用 `serve.py` 是因为 ES module + importmap 不能用 `file://` 直接打开，且它带 no-cache 头，改完刷新就生效。

## 这栋楼现在长什么样

楼是东西向长条，三层，`FH = 4` 米一层（`FLOORS = 3`）。北侧一整排房间，南侧是外廊走廊，走廊外沿是护栏。

```
x:  -34      -28        -14        0         14        26    32
    ┌────────┬──────────┬──────────┬─────────┬─────────┬──────┐
    │ 楼梯间 │ 教室(伪) │ 教室(真) │ 教室(伪)│  厕所   │楼梯间│   ← 北侧房间
    │        │          │  ★主教室 │         │(更深)   │      │
    ├────────┴──────────┴──────────┴─────────┴─────────┤      │
    │              走廊（南侧是护栏，能看到楼下）        │      │
    └──────────────────────────────────────────────────┴──────┘
                                              x21.5~26 ┐
                                                       │ 连廊（两面护栏）
                                                       │ z3.4~13
                                                       ▼
                                              ┌──────────────────┐
                                              │   老师办公室      │ x14~28, z13~22
                                              └──────────────────┘
```

- **走廊**：`z ∈ [-10, 3.4]` 里 `z > 0` 那半条是走廊，南沿 `Z1 = 3.4` 是外廊护栏（密集竖杆 + 上下双横杆，按实拍照做的）。
- **房间进深**：教室 `z ∈ [-10, 0]`，前墙开 4 扇观察窗（左右各两个）+ **前后两个门**（后门在 `x1` 端、前门在 `x2` 端，也就是黑板讲台那一头），符合图纸"每个教室都开四个窗户"，也保住《第一关设计》里的两条离场路线（后门 7.6m 低风险 / 前门 14m 高风险）。
- **厕所**比教室更深（`z` 一直到 `-14`），最里面北墙有高处开窗，内设 4 个隔间 + 小便池 + 洗手台 + 拖把池。
- **楼梯间**在东西两端（`-34~-28` 与 `26~32`），双跑楼梯：先往北跑一段 → 中间平台 → 再往南跑一段回到走廊标高。楼梯间北墙收窄到 `STZ0 = -5.2`，不再多出一截空地。
- **连廊**：3F 外廊护栏在 `x21.5~26` 处断开，向北伸出一条两面护栏的悬空连廊，尽头接**老师办公室**（和走廊呈 L 形，右上角那个矩形）。
- **老师办公室**：`OFF = { x1: 12, x2: 32, z1: 13, z2: 23 }`（20×10，v0.5 按手绘图放大，给后面的博弈留空间）。南墙是**一扇和连廊同宽的门**（不是开口），西墙挂一整块黑板，北墙两窗 + 东墙一窗，里面是 **3 张正方形办公卡座**（每张被十字挡板分成 4 个工位，挡板顶到离地 1.41m —— 站着能探头，蹲下就挡住），另有文件柜、两摞"高高的作业本"、两盆大绿植、饮水机、灭火器、海报、米色窗帘。
- **3F 走廊**天花板下沿挂了一条红底横幅（"距离高考仅剩 002 天"风），挂在 `y+2.86` 高度，不挡"低头看楼下"的视线。

### 胜利条件

**翻矮墙进跑酷 → 跑完才算通关；其余三条路照旧"出墙即逃学成功"。** 所有路线都必须**先在校内待过**（`hasBeenInside`）：开局坐标若落在墙外（比如地址栏残留了调试参数），不会误判通关。
副标题：从大门出去 → "逃学成功 · 大摇大摆走出校门"；狗洞 / 其它边翻墙 → "逃学成功 · 翻墙出去了"；跑酷跑完 → "逃学成功 · 用时 X 秒 · 摔了 N 次"。

#### 跑酷规则

- **计时**：初始 90 秒，右上角面板显示 `剩余时间 m:ss` + 进度条（剩 20 秒以下变红）+ 当前检查点。
- **检查点 5 个**：山脚 → 一级台地 → 半山腰 → 西北坡 → 小吃街。只认"下一个"，必须顺着路线一个个过。
- **摔了**：落地速度 > 8.5 m/s（约 1.4m 以上的落差）且不在 `groundOK` 三块里 → **扣 6 秒**，文案"班主任在下面喊了一嗓子 / 掉下来了 · 剩余时间 -6 秒 · 回到XX"，退回最近检查点。柱子之间正常上下坡（0.8m，落地速度 ≈6.4）不罚。
- **时间归零**：判被抓（`班主任巡查 · 时间到了，被堵在了后山`）。
- **翻回墙里**：跑酷作废，交还校内逻辑（不判失败，只是白跑一趟）。
- 跑酷期间校内那套（楼层 / 教室 / NPC / 可疑度 / 巡查 / 搜捕）全部停摆，可疑度面板隐藏、楼层标签显示"后 山"。

53. **地面弧线怎么画都难看**（v0.15，试了四种）→ ①一串 `BoxGeometry` 沿切线旋转拼圆弧：墨线渲染按几何边描轮廓，每段盒子都带自己的四条边框，放大是一串"毛毛虫"；②`ExtrudeGeometry` 拉伸环形扇区：侧壁由几十个小平面拼成、法线各不同，后处理的法线边缘检测在段间再画线，放大是"缝合线"；③`RingGeometry` 整片 `fill: true` 实色环带：连续了，但**明显比场地直线粗**（直线是 0.12m 宽的空心盒子，墨线只描它的两条边，看起来是两条细线）；④**最终**：`RingGeometry` 画**两条细环带**（内沿 `r-w/2`、外沿 `r+w/2`，各宽 0.028，中间留空），和直线的"双细线"观感一致。另有一个坑：虚线模式的 `0.72` 系数一开始写死在所有分支里，实线弧线也只画 72%，断成一段段 —— 必须 `const frac = o.dash ? 0.72 : 1;`。

54. **教师停车棚里长出三棵树**（v0.16）→ 东南角生活区那排树写的是 `tx = 21.0 + i*9.5, tz = 63.4`，而教师停车棚占 `x 20~44 / z 58~65` —— 前三棵（21 / 30.5 / 40）整棵落在棚里，树干戳在棚下、树冠（离地 2.9 起、高 5.1）直接捅穿 2.42m 高的顶棚，截图里就是"树从车棚顶上长出来"。整排退到棚北侧 `tz = 55.2`（树冠半径 1.4，最南到 56.6，离棚顶 57.6 还有 1m）。**教训：摆"附属物"（树 / 长椅 / 路灯 / 垃圾桶）之前，先把同区域所有 `box` 占位的 AABB 列出来对一遍 —— 这个棚的坐标写在 1000 行开外，光看树的代码根本想不到它压着什么。**

55. **门卫室电视墙的屏幕怎么画都不像屏幕**（v0.16，试了三版）→ ①一层 `fill: true` 黑块 × 12：12 块糊成一整面黑板，完全看不出是"一排屏幕"；②黑外框 + **纸白内屏**：有层次了，但读成"一排相框"（截图 `GD1_inTV.png` 确认）；③**最终**：黑实心外框（1.4 × 0.52）→ `INK.BLUE` 实心屏面（四周各缩 6cm）→ 屏内一道纸白高光条，才读得出"亮着的监视器"。另外行距第一版是 0.57，三条几乎贴在一起，读成"三个抽屉"；改成 0.72（屏间留 0.2 空隙）才对。值班台同理：第一版整块 `INK.BLUE` 实心，10 米长的蓝板子比电视墙还抢眼，改成纸白台体 + 黑描边 + 三道抽屉缝。**教训：在这套墨线渲染里，"屏幕"必须同时有深色屏面 + 一圈框 + 一点高光，少一样就变成别的家具。**

56. **杂物间门口"横一根杆、浮一块绿布"**（v0.17）→ 西隔墙的挂衣杆写的是 `box(ST.x1 + 0.06, y2 + 1.55, ST.z1 + 3.2, 0.05, 0.05, 1.8, ...)` —— 中心 `ST.z1 + 3.2`、长 1.8，跨 `z 2.3 ~ 4.1`；而门洞是 `[[ST.z1 + 3.0, ST.z1 + 4.3, 0, 2.0]]`，**杆子正好横穿门洞**，绿抹布（中心 `ST.z1 + 3.3`）就挂在门洞正中。整组挪到门洞南侧 `ST.z1 + 6.05 ~ 6.85`。**教训：`gaps` 里开出去的洞口，就是墙面上"什么都没有"的一段，挂件 / 画框 / 挂钩 / 消防栓一律要避开这段区间 —— 光看挂件的坐标想不到它压着门洞。**

57. **杂物间的门怎么摆都不像门**（v0.17，试了三版）→ ①门扇平贴墙面、和门洞重叠：门板堵在门洞里，读成"墙被砌死了"；②门扇**垂直于墙面**往大厅伸出去（想表达"开着"）：门板正好和视线平行，从大厅正对门洞只能看到一条 5cm 的边，等于没有门（截图 `HD1_door.png` 确认）；③**最终**：门扇**平行墙面**、整体挪到门洞南侧旁边（`ST.x1 - 0.135`、中心 `ST.z1 + 4.95`，宽 1.3 沿 z），读成"门被推到 90° 靠在墙上"，正面一眼能认出是门（截图 `HE1_door.png`）。把手要装在这块门板**靠门洞的那一端**（`ST.z1 + 4.45`），否则把手悬空。**教训：这套几何只能摆不能转，"门开着"只能靠"门板挪到门洞旁边、平行墙面"来表达，垂直伸出来一定会被透视压成一条线。**

58. **后山读成"一栋带楼层线的白楼"**（v0.18，外观返工四轮）→ 第一版三级台地是三个规整长方体，侧面每 0.66m 一道**通长**横线，远景里完全就是三层楼的窗格（截图 `PA1_hillFar.png`）。①改成每层拆 3 段不等长短横线（`strata`）—— 底边锯齿化了，顶边还是三条笔直水平线；②加碎石裙 `skirt()` 打散底边直角 —— 顶边照旧；③加顶边石脊 `crest()`，但**等距（2.6m 一块）+ 尺寸相近 + 全都咬在边线上**，整座山读成"三层整齐码放的纸箱"（截图 `PD1_far.png`）；④**最终**：间距拉到 4.5m、宽 `0.9~3.4`（三倍方差）、高 `0.25~1.9`、沿法线随机内缩 `0~1.6m`（不再全咬边线）、约四成位置叠第二块小石，山顶轮廓才成为参差的山脊（截图 `PE1_far.png`）。崖壁岩块同理：等距撒 = "贴瓷砖的墙"，必须降到 `len/11` 的密度、位置完全随机、只留零星几块大石。**教训：随机撒石头时，"等距 + 尺寸方差小 + 都咬在轮廓线上"这三条凑齐任意两条，一定读成人工码放的砖块。**

59. **跑酷的"摔了"判定在山脚走两步就触发**（v0.18）→ 第一版判据是 `bp.y < groundY + 0.5`（站在山脚地面上），但**山脚和台地底下是同一片地面**，y 上根本分不开，玩家在山脚正常走路就被判"掉下去了"。改成按**落地瞬间的下落速度**：`vy = (pk.prevY - bp.y) / dt`，落差 h 的落地速度 `sqrt(2*26*h)` —— 0.8m（柱子之间正常下坡）≈6.4、1.6m≈9.1、2.4m（一级台地）≈11.2，阈值取 **8.5**：走柱子下来不罚、从台地直接掉下来才罚。另加 `groundOK` 三块矩形（起点 / 西北下山段 / 小吃街）本来就该落地，一律不罚。**还有一处必须配套**：`pkBackToCp()` 里要把 `pk.prevY` 重置成检查点高度 —— 传送会瞬间跳高度，不重置下一帧就算出巨大的"落地速度"，刚回检查点又被判一次摔。

60. **跑酷路线第一版 4 处"跳不过去"是核算方式错**（v0.18）→ 用"点对点中心距"算可达性，报出 4 处 FAIL，其实全是把台地当点算导致的假报警（柱 3 直接贴着台地边、柱 4 在台地 1 内部、柱 6 在台地 2 内部）。改成"**柱到矩形最短距离 + 柱到柱边缘空隙**"后全程可达。另外台地 2 顶面必须走"西缘 → 北缘"两段折线，直线斜穿会在半路出边界掉到台地 1。最后用真实物理脚本 `_t_pk_walk.mjs`（`World` + `makeBody(pos, 0.34, 1.75, 0.55)`、dt=1/60、跳跃策略"目标更高或前方 0.85m 处地面低 0.35 以上时，在距离 0.7~1.9m 起跳"）跑通 17 个航点，**1592 帧（约 26.5 秒）**。**教训：①可达性核算要按碰撞体形状算，不能按坐标点算；②"卡住就跳"的 AI 一定跳早撞侧壁，必须按距离提前量起跳。**

61. **终点横幅上的"字"贴到了背面**（v0.18）→ 街北口那条纯红横幅远看就是一块红板子，和两边摊位顶上的红布糊成一片，读不出"这里是终点"。加四道纸白短条当"字"，第一版写在 `fz - 0.05`（横幅北侧、背面），玩家从街上由南往北走过来**完全看不见**，横幅还是纯红一块（截图 `PN1_goalLine.png` 确认）。改成 `fz + 0.05`（横幅**朝玩家这一侧**）才对，截图 `PO1_goalFar.png` / `PO2_goalMid.png` 里四道白条清清楚楚。**教训：这套渲染没有双面材质的概念，贴在薄板上的装饰必须放在玩家会看到的那一面；判断"哪一面"要用玩家的行进方向，不是用坐标大小。**

62. **跑酷检查点不能"跳着吃"**（v0.18）→ 试过"上到半山腰之后允许直接吃最后一个检查点（小吃街）"，想着摔进街里时不用爬回西北坡重走。实际跑起来发现：台地 1 西北角本来就在 `groundOK` 里（落地不罚），从那里往北走几步就进了街，**整段西北坡被跳过** —— 那就不是"绕山半圈"了。改回严格"只认下一个检查点"（`pk.cp + 1`），要抄近路就得先掉下去扣时间。**教训：给玩家"容错"的规则，先想清楚它会不会顺手把设计意图也容错掉。**

## 保留的设计（当前构建暂时关闭）

下面这套玩法层代码都还在（`npc.js` / `game.js`），只是 `npcs: []` 所以不跑。加回 NPC 就复活。

### 两层数值，各管各的

| 数值 | 属于 | 涨法 | 结果 |
| --- | --- | --- | --- |
| **可疑度** `heat` | 玩家全局 | 事件驱动，干一件事跳一截（翻窗 +8、被盘问失败 +25、教室被抓 +30、全校搜捕结束 +25） | 满 100% 触发全校搜捕 |
| **注意值** `notice` | 每个 NPC 各自 | 看见你 / 听见你时按距离累计，速率 `(100 / max(0.7, dist * 0.6)) * heatScale`，其中 `heatScale = 1 + heat / 80` | 满 100 进入追击 / 盘问 |

注意值必须累计**暴露 0.5 秒以上**才起效，蹲在课桌后（`hasCover`）或坐在座位 1 米内（`nearSeat`）完全看不见。

### NPC 行为状态机

```
PATROL ──看见/听见──> SUSPICIOUS ──notice 满──> CHASE ──追上──> TALK
   ▲                       │                      │              │
   └──── RETURN ◄──────────┴──────────────────────┴──────────────┘
```

- `PATROL`：沿 `patrol` 巡逻点走，`waitAt` 秒一停。
- `boardMode`：讲台老师专用，四相位循环「写字 4.0s → 停笔 0.6s → 转身 2.0s → 转回 0.8s」，只有转身那 2 秒能看见下面。
- `SUSPICIOUS`：朝玩家方向看，`lostT` 超时回 `PATROL`。
- `CHASE`：速度 `chaseSpeed`（主任 5.95，略快于玩家跑速 5.6 —— 所以跑不掉，得躲）。
- `TALK`：盘问，对话期间全场暂停。

### 脚步声

| 状态 | 噪音半径 |
| --- | --- |
| 静止 | 0 m |
| 蹲行 | 2 m |
| 走 | 6 m |
| 跑 | 11 m |

### 盘问选项（三轮，一次比一次难糊弄）

| 轮次 | 选项通过率 |
| --- | --- |
| 第 1 轮 | `1.0` / `0.55` / `0` |
| 第 2 轮 | `0.40` / `0.30` / `0` |
| 第 3 轮 | `0` / `0.15` |

同一个人记得你被问过几次，持有"数学试卷"时伪装成功率 100% / 40% / 0% 递减。通过 +8 可疑度，失败 +25 并直接进追击。

### 全校搜捕

可疑度满 100% → `raidT = 8` 秒倒计时，所有 NPC `silent = true`、`notice = 100`、直接进 `CHASE`，从四面八方堵你。撑过 8 秒 → 可疑度 -8 解除；被碰到 → 直接 gameover。

### 班主任巡查 = 硬时限

`bellT = 300` 秒。HUD 右上角倒计时，归零直接触发全校搜捕。这是"必须动起来"的压力源。

## 楼层隔离（箱庭）怎么做的

一句话结论：**你要的是隔离，不是加载。**

需求原话是"从三楼下到二楼重新加载一下，别的除了二楼之外就不加载机制"。按这个目标，真正卸载/重建场景是负优化：

- 渲染不是瓶颈 —— 每层几何按 ink 合并后总共才 5 个左右 draw call，全楼一起画和只画一层没区别。
- 真加载要序列化 NPC 状态、已拾取道具、已开的门、巡逻进度……一旦漏一个就是难查的存档 bug。
- 而且玩家还要"低头看楼下绿化带和校门"，本来就要求楼下是画出来的。

所以做成 **逻辑冻结 + 假加载**：

| 层 | 做法 |
| --- | --- |
| 几何 | 全楼始终渲染，不卸载 |
| NPC | `npc.floor` 字段；主循环 `if (n.floor !== curFloor) { n.sees = false; continue; }` —— 不动、不看、不听、不追、注意值不涨 |
| 交互 | 拾取物按 `|p.y - player.y| > 1.8` 过滤（上下层课桌 xz 完全重叠，不过滤会隔层拿东西）；校门只在 1F；座位要求同层 |
| 搜捕碰撞 | `if (n.floor !== curFloor) continue;` |
| 头顶注意条 | 非同层直接隐藏 |
| 切换表现 | 0.5 秒淡出淡入（`#fade` 米色蒙层，HUD 压在上面），黑场最深时瞬移 + 更新楼层标签 |

已知三个坑（都写在这里，暂时没改）：

1. **主任追你时你下楼 = 直接安全**：他会被冻在楼上。合理做法是"追到楼梯口停住徘徊 3 秒"，让他有存在感。
2. **切换点在楼梯口按 `E`**：现在按一下就整段瞬移，中间那段楼梯白跑了。可以改成"走完第一跑才切"。
3. **1F / 2F 还是空壳**：只有楼梯间和走廊能走，教室全锁。等玩法回来再填。

## 已知限制

- **没有敌对生物**：`npcs: []`，这一版纯看楼。
- 办公室刚补过道具（3 张十字隔断卡座 + 每工位显示器/文件架/小绿植/椅子、西墙黑板、文件柜、两摞高高的作业本、两盆大绿植、海报、米色窗帘、吸顶灯），但仍偏"样板间"。
- 1F / 2F 是空壳：教室全部锁死，只有楼梯间和走廊可用。
- 美术全是占位盒子（墨线 + 排线风格），没有贴图。
- 教室里不再强制蹲（v0.13 取消了），蹲不蹲由玩家自己按 `Ctrl` 决定；`inClassroom` 字段还在，留给以后 NPC 的视线判定用。
- 花圃里的草铺得比较满，几乎看不到土面（视觉密度问题，暂不调）。
- 后山跑酷场：**没有移动平台**（`world.removeBox` 内部会 `finalize()` 重建一千多个碰撞盒，每帧重建会掉帧），**没有攀爬 / 抓边**（落差一律 ≤ 0.9m，靠石柱一级级跳），**不能做斜面**（碰撞盒永远是轴对齐的，山坡只能拿阶梯 / 台地叠）。掉下去是"扣时间 + 回检查点"，不判死。
- 跑酷没有中途存档：一旦翻出矮墙进了跑酷，摔了只会回检查点，退出只能翻回墙内（跑酷作废）。
- 后山跑酷的计时器只在跑酷期间显示，跑完（或时间到）面板会收起；成绩只显示一次，不进记录。
- 椅子搬起来没有"抱在手上"的表现（拿走就消失），也还不能放下。
- 办公室那扇门能开能关，但门扇只有 7cm 厚、没有门锁音效，开关是瞬时的（没有推门动画）。
- 校园里现在只剩主路两侧的行道树和前广场一排，操场与篮球场里一棵树都没有（v0.8 全删了）；跳远场地也只是静态摆设，还不能真跳。
- 食堂二楼地面抬到 `3.55` 之后，`floorOfY(3.55) = 1`，也就是说**食堂二楼会被楼层判定当成"二楼"**：HUD 标签会从"一 楼"变成"二 楼"，如果以后在食堂放 NPC，得把它们的 `floor` 设成 1。这是拉高层高的副作用，语义上没毛病（它确实是二楼），但现在上下食堂楼梯会看到楼层标签跳一下。
- 器材室翻找**没有翻找动作动画**：现在有 2 秒进度条、有可疑度代价，但人物只是站着不动（没做弯腰翻箱子的姿态）。
- 杂物间里那把椅子没有特殊外观标记（就是一把普通的橙椅子，只是有一条腿短 6cm），玩家得靠"这屋只有它能交互"来分辨。
- **围墙外那一片纯背景**：远景楼 / 电线杆 / 自行车 / 行道树 / 路灯都没有碰撞体以外的意义，也没有任何交互；玩家翻出围墙立刻判胜，走不到跟前。远景楼为了能露在 3.27m 围墙上面，高度做到 30~48m（现实里 8~13 层），是刻意夸张的。
- 篮球场标线是**按 FIBA 比例缩过**的：这块台地 20×15，真实球场 28×15，长边短了 8m。横向（z，净宽 13.8）保持真实比例，三分线 / 罚球圈半径按真实尺寸不改；纵向（x）只缩"到底线的距离"，限制区深度仍是 5.8。所以三分弧比真实场地更靠外一点（台地窄，缩不动）。
- 篮球场标线是**平面贴片**，没有厚度也没有碰撞体，玩家从上面跑过不会绊到。
