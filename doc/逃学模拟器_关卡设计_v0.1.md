# 《逃学模拟器》关卡设计文档 v0.1

> 范围：教室出逃 → 校门离开之间的**中段关卡链**
> 体裁：3D/2.5D 箱庭潜行（参考《一鹅当先》《Untitled Goose Game》《杀手》的"区域+伪装"结构）
> 单局时长：12–18 分钟；失败不是死亡，是"被拎去教导处"

---

## 0. 一句话基调

**你不是特工，你只是一个想在第三节课后溜出学校的高二学生。你的武器是校服、试卷、一张嘴，和这所学校本身的一切漏洞。**

---

## 1. 设计支柱

| 支柱 | 含义 | 反例 |
|---|---|---|
| **一个箱庭，一个动词** | 每个区域只教/考一个新机制，不重复 | 每个走廊都是"躲视线" |
| **合理化伪装** | 被发现不等于失败，能"编理由"过关 | 纯硬核潜行 |
| **校园即关卡** | 掩体、道具、NPC 全来自真实校园物件 | 凭空造机关 |
| **日程驱动** | 同一个空间在不同作息时段规则不同 | 静态关卡 |
| **失败很轻** | 检查点密、被抓有喜剧演出 | 惩罚性重开 |

## 2. 核心系统

### 2.1 玩家状态

- **怀疑值（0–100）**：被盘问、被目击异常、答错问题会上涨；满值 → "请去教导处"。
- **体力**：跑、翻、爬消耗；蹲行慢但隐蔽。
- **伪装状态**（可切换）：
  - `正常行走` — 最不起眼，但被巡逻者盯着看会触发盘问
  - `手持试卷` — 对"教学线"NPC 有豁免（"去办公室问问题"）
  - `手持请假条/医务条` — 对门卫有效
  - `值日生（拖把/水桶）` — 可进入走廊中段、可解释停留
  - `体育课学生（抱球）` — 可进操场、器材室
  - `校服反穿/塞书包` — 降低"本校学生"识别度，但增加"可疑"基础值
- **时间/作息**：上课铃、下课铃、眼保健操、大课间、午休、升旗、消防演练。**同一关卡，时段不同，NPC 分布不同。**

### 2.2 NPC 感知模型

| 通道 | 规则 |
|---|---|
| 视觉 | 锥形视野（60–90°，8–15m），受掩体遮挡；蹲下缩短发现距离 |
| 听觉 | 跑动、开门、打翻东西、拉闸；可用环境音掩盖 |
| 记忆 | 同一 NPC 第三次看到你会主动盘问 |
| 盘问 | 靠近 → 进入对话，检查"手上拿什么 / 从哪来 / 现在几点" |

### 2.3 盘问 = 一次小型"证件检查"

```
陈主任："站住。哪个班的？这个点不上课，干什么去？"
玩家选项：
  A. "老师让我去办公室问问题"   → 需：手持试卷 + 朝向办公室 + 不在教室反方向【通过】
  B. "我去趟厕所"               → 需：裤兜有纸 / 厕所方向 / 不是刚从教室溜出【通过】
  C. "我帮老师搬东西"           → 需：手持教具/作业本【通过】
  D. 沉默 + 转身跑               → 直接 +40 怀疑，触发追逐
```

**关键设计：同一理由第二次用会被识破**（"你上午不是问过一回了？"）——逼玩家换招。

### 2.4 日程 = 动态关卡

| 时段 | 走廊 | 操场 | 校门 |
|---|---|---|---|
| 课间 10 分钟 | 人流爆满，主任在 | 没人 | 无人 |
| 上课中 | 空，但老师可能出来 | 空 | 铁门锁 |
| 眼保健操 | 全员闭眼在教室 | 空 | ——（可利用） |
| 大课间跑操 | 空 | 全员 | 锁 |
| 午休 | 半空，值班老师 | 少数 | 家长接送潮 |
| 升旗仪式 | **全空**（反向利用） | 全员 | 锁 |
| 消防演练 | 混乱、烟、疏散人流 | 集合点 | **最容易混出** |

**核心思路**：教学楼是"枢纽"，操场是"开阔漏斗"，校门是"唯一有对话的终点"。玩家有 4 条通往校门的路线，每条经过不同的箱庭组合。

## 4. 关卡详解

### 4.0 教室（序章 / 教学关，2 分钟）

- **空间**：本班教室，玩家坐最后一排靠窗。
- **NPC**：数学老师（背对写板书，每 25 秒回头一次）。
- **机制**：`时机`——黑板写满 → 转身 → 擦黑板。趁"擦黑板"的 6 秒从后门溜出。
- **教学**：移动 / 蹲 / 互动 / 举手。
- **支线**：先举手"老师我要上厕所"→ 合法离开座位，但会被要求"快去快回"，回来晚触发班主任查岗。
- **校园细节**：后排趴睡的同学、转笔、黑板报、吊扇、窗外的树、后门上的小玻璃窗（班主任最爱从这偷看）。
- **失败**：被老师回头看见离座 → 全班哄笑 + 罚站 → 重开。

---

### 4.1 走廊（**核心潜行关**，5 分钟）★

> 这是整个游戏的"垂直切片"，建议第一个做。

- **空间**：约 40m 直走廊，两侧各 4 间教室，一侧有窗（朝内院）。墙上：班级牌、卫生流动红旗评比栏、宣传栏、消防栓箱、垃圾桶、饮水机、拖把桶+“小心地滑”牌、绿萝。
- **NPC**：
  - **教导主任 陈建国**（外号陈扒皮）：从东端办公室出发 → 西行到底 → 转身返回，周期约 40 秒。视野 12m / 60°，步速慢，**会在宣传栏前停 3 秒看手机**。
  - **班主任李老师**：随机从某教室后门出来去厕所，短暂。
  - **值周生（红袖章）**：站楼梯口查迟到，只查"跑的人"。
- **核心机制 = 视线锥 + 掩体 + 试卷伪装**

**掩体清单（都要能蹲）**：

| 掩体 | 效果 | 副作用 |
|---|---|---|
| 门框凹陷处 | 完全遮挡 | 无 |
| 垃圾桶 | 遮挡下半身 | 蹲久了会被值日生骂 |
| 拖把桶 + 警示牌 | 完全遮挡 | 撞倒会发出巨响 |
| 宣传栏凸出 | 遮挡 | 贴太近会碰掉奖状（掉怀疑值） |
| 消防栓箱 | 遮挡 | 玻璃门可当镜子看身后 |
| 楼梯转角 | 脱离视野 | 无 |

**试卷伪装流程（核心玩法）**：

1. 从某教室讲台 / 垃圾桶 / 宣传栏夹缝拿到 **《数学周测卷（未做）》**。
2. 手持卷子 = 进入"问问题"伪装。
3. 正面撞上陈主任 → 触发盘问：
   - 选 **"老师让我去办公室问问题"** → 需满足：手上有卷子 ✓ / 面朝办公室方向 ✓ / 不是刚从教室溜出 ✗
   - 通过 → 陈主任点头："去吧，问完赶紧回。" → **30 秒内不再盘问你**。
4. **反直觉设计**：手持试卷却往楼梯/操场方向走 → 反而可疑（"问问题往楼下走？"）。
5. **识破**：同一 NPC 第二次问同样的话 → "你上午不是问过了？" → 怀疑值 +30。

- **失败**：盘问答错 / 超时 / 被目击从教室溜出 → 怀疑值满 → 被拎去教导处 → 回到走廊起点检查点。
- **隐藏情报**：帮值日生倒垃圾 → 他告诉你"陈扒皮每节课间都去三楼厕所"（解锁厕所关的先手）。
- **校园细节**：评比栏里某个班的牌掉了一个字；消防栓玻璃映出身后的主任；地上粉笔头；拖把水渍；上课铃是《致爱丽丝》；窗外传来广播体操前奏。

**教学意图**：一次性把"看 → 藏 → 编"三件事教完。

---

### 4.2 楼梯间（**潮汐 / 混入人流**，3 分钟）

- **空间**：3F→2F→1F，两跑楼梯，转角平台，**凸面镜**，消防门，扶手。
- **NPC**：学生潮（大课间 200 人上下楼）、保洁阿姨、值周生。
- **机制 = 逆流与混入**：
  - 上课铃前 60 秒，人流**向上**（回教室），玩家要**向下**——逆流最显眼。
  - **混入**：贴着一群同向学生走，怀疑值不涨；独自逆流 → 每 2 秒涨 3 点。
  - **凸面镜**：站特定角度可看到上一层楼梯口有没有老师。
  - **制造混乱**：推倒拖把桶 → "有人滑倒了" → 人群聚集 5 秒 → 逆流窗口（但隐藏"破坏公物"值 +1）。
- **校园细节**：扶手当滑梯、墙上鞋印、转角"上下楼靠右行"标语、消防栓。
- **变奏**：如果触发了消防演练，这里变成"顺着人流被冲下去"，完全不同的体验。

---

### 4.3 教师办公室区（**静音潜行 / 偷取**，3 分钟）

- **空间**：办公室外一条窄走廊；办公室门半开，里面 8 个工位。
- **NPC**：批作业的老师、打电话的老师、打印机、饮水机。
- **机制 = 声音管理**：
  - 走廊是"安静区"：跑步/跳跃/开门声 → 里面老师出来查看。
  - **掩声窗口**：打印机工作 5 秒 / 饮水机接水 / 电话铃响 → 趁噪音快速通过。
  - **门缝观察**：贴近门缝可看老师朝向（背对 = 可进）。
  - **目标**：拿空白请假条（靠门桌上），或偷盖班主任的章。
- **失败**：被老师抬头看见 → "你是哪个班的？进来。" → 盘问。
- **校园细节**：教师风采照片墙、绿萝、保温杯、颈椎按摩仪、堆成山的卷子、红笔、门口"教师办公室 请勿喧哗"。

---

### 4.4 厕所 / 水房（**安全屋 + 突发巡查**，2 分钟）

- **机制**：洗手 = **存档点** + 回复体力；但会**随机触发巡查**。
  - 教导主任来查抽烟/玩手机 → 躲隔间。
  - 隔间有"好门/坏门"之分，坏门会被一把推开。
  - **换装点**：校服反穿、塞进书包、换体育服。
- **校园细节**：镜子、洗手台、纸巾、门板上的小广告、拖把、"来也匆匆去也冲冲"。
- **设计意图**：给玩家喘息，同时把"存档"和"风险"绑在一起（不能无脑存档）。

---

### 4.5 连廊 · 实验楼（**监控规避 / 断电解谜**，4 分钟）

- **空间**：连接教学楼与实验楼的玻璃连廊，**顶部两个监控摄像头**（红灯）；实验楼有音乐教室（钢琴声）、美术教室（石膏像）、体育器材室。
- **机制 = 视线投射 + 环境解谜**：
  - 摄像头视野**投射为地面红色光斑**，周期扫动。
  - **死角**：柱子后、消防箱后、展板后。
  - **断电**：楼梯口配电箱拉闸 → 摄像头停 20 秒，但 60 秒后电工来查（新增巡逻）。
  - **道具**：篮球（抱着 = 体育课学生）、画板（挡脸/挡摄像头）、实验服。
- **校园细节**：走调的钢琴、松节油味、石膏像、器材室的垫子和篮球架、墙上"实验重地"。
- **设计意图**：从"躲人"升级到"躲系统"，节奏变慢、变算计。

---

### 4.6 食堂 · 小卖部（**资源与社交**，3 分钟）

- **空间**：食堂后门、泔水区、小卖部窗口、餐桌区。
- **机制 = 交易 / 伪装**：
  - 校园卡/零花钱 → 买辣条、冰棍（可当"贿赂"道具）。
  - **帮食堂阿姨搬菜** → 获得两条情报：后门几点开 / 送货车几点来。
  - **推"营养餐车"** → 可穿过整个后厨通道（最强伪装，但推车时不能跑、不能蹲）。
- **校园细节**：不锈钢餐盘、广播"光盘行动"、老干妈、冰柜、油烟、泔水桶、墙上的"节约粮食"。
- **设计意图**：引入"用资源换路线"，让玩家第一次意识到"可以不用潜行"。

---

### 4.7 操场 · 中庭（**开阔地 / 距离管理**，4 分钟）

- **空间**：400m 跑道、足球场、看台、升旗台、单杠区、绿化带。
- **NPC**：体育老师（哨子，视野远）、跑操队伍、打球的学生。
- **机制 = 借人群 / 距离**：
  - 开阔地**没有掩体**，只能靠"混进人群"和"贴边"。
  - 混进跑操队伍 → 跟着跑，NPC 不会单独注意你。
  - **看台下方**、绿化带灌木 = 唯二硬掩体。
  - **升旗仪式**：全员集合 → 教学楼全空（反向利用，见第 6 章隐藏路线）。
- **校园细节**：塑胶跑道、国旗、广播体操、哨子、体育老师墨镜、看台上的班级方阵。
- **设计意图**：把前面积累的"藏"全部收走，逼玩家用"混"。

---

### 4.8 后墙 · 后门（**攀爬 / 物理解谜**，3 分钟）

- **空间**：2.2m 后墙、垃圾桶、树、快递柜、垃圾房、配电房、狗洞。
- **机制 = 找攀爬点**：
  - 垃圾桶 → 墙头；树 → 墙头；快递柜 → 墙头。
  - **狗洞**被铁丝网挡，需要钳子（器材室/后勤）。
  - **后门**需钥匙（食堂阿姨）或跟送货车。
  - **风险**：墙上"禁止翻越"监控、流浪猫叫、**衣服被挂破**（外观变化 → 校门处可疑度上升）。
- **校园细节**：快递柜、外卖架、"禁止翻越"红漆字、流浪猫、爬山虎。
- **设计意图**：平台跳跃 + 资源检查，给"硬核玩家"一条不靠嘴的路线。

---

### 4.9 校门（**终局 / 对话盘问 + 凭证链**，4 分钟）

- **空间**：校门、门卫室、值班老师、家长接送区、公交站。
- **NPC**：门卫老张（会问三个问题）、值班老师、红袖章值周生。
- **机制 = 凭证链**：
  - 老张会**交叉验证**：请假条上的班主任签名 + 今天请假记录 + 家长电话。
  - 通过方式：
    - **A 真请假条**：办公室偷盖的章（4.3）+ 班主任签名（需观察字迹）
    - **B 假请假条**：自己写 → 字迹/章会被识破（高风险）
    - **C 家长接送**：打电话给"家长"（实际是同学）→ 需提前在 4.6 用辣条收买
    - **D 混放学人流 / 校车 / 送货车**（4.6 情报）
    - **E 翻墙**（4.8，绕过校门）
    - **F 医务室转院**：装病 → 医务室条 → 老张放行（需演技 QTE）
- **失败**：答错 / 紧张 QTE 失败 / 拖到放学铃响（人流冲散，老张锁门）。
- **校园细节**：门卫室的小电视、登记本、电暖器、校门口"接送区"牌子、"外来人员请登记"。
- **设计意图**：把前面所有道具/情报收束成"一张凭证网"，是整局的考试。

## 5. 关卡连接与节奏

```
教室(教学) → 走廊(核心) → 楼梯(变奏) → ┬ 办公室(静音)
                                        ├ 厕所(安全屋)
                                        └ 连廊(监控) → 操场(开阔) → 后墙/校门(终局)
```

- **每箱庭 2–5 分钟**，检查点：厕所、食堂、门卫室旁。
- **节奏**：紧张（走廊）→ 喘息（厕所）→ 算计（连廊）→ 紧张（操场）→ 高潮（校门）。
- **可自由探索**，但"作息表"会推动时间，拖太久会进入不利时段。
