# 如何新增一个场景

> 面向策划/程序。读完能独立加一个场景，不用懂引擎内部。
> 适用架构：`src/scenes/` 场景层 + `src/reusable/` 可复用资源层。

---

## 0. 先搞清三个词

| 词 | 含义 | 例子 |
|---|---|---|
| **场景(scene)** | 一次加载的整张世界，一个文件夹 `src/scenes/<场景id>/`。**场景多大由你定**——可以是一层楼，也可以是半层、几间房。 | `floor3`（整个三楼） |
| **房间(room)** | 场景内部的一块矩形空间，多个房间拼成一个箱庭，靠**门**连通 | 我的教室、走廊、教师办公室 |
| **箱庭(sandbox)** | 就是「由多个房间拼成的场景」这种形态，不是单独的东西 | 三楼这个场景本身 |

> 一句话：**场景 = 一个文件夹；里面用「房间 + 门」搭出你要的世界形状。**
> 这次三楼是一个「整层」场景，下次你想要「两层」「一栋楼」「操场+教学楼」都行，规则一样，只是 `ROOMS`/`DOORS` 写多点。

---

## 1. 一分钟总览

一个场景 = **一个文件夹** `src/scenes/<场景id>/`，里面放：

| 文件 | 放什么 | 必须吗 |
|---|---|---|
| `index.js` | 场景主体：房间、门、家具、敌人、拾取物、出生点 | 必须 |
| `resources.js` | 只在这一场景出现的独特模型/装饰（可选） | 可选 |

做完后到 `src/scenes/registry.js` 登记一行，就能在 main 里加载。

> 判断「可复用」还是「场景独有」：
> - 书本、课桌、椅子、门框、储物柜 → **可复用**，用 `src/reusable/resources.js` 现成的，或加到全局 prefab 库。
> - 教导主任（只某场景有）、只在某个房间里的数学老师、某个场景独有的机关 → **场景独有**，写在场景文件夹里。

## 2. 三步加一个场景

### 第 1 步：复制 `src/scenes/floor3/` 当模板

它就是一个完整场景：多个房间 + 门 + 教室完整布置 + 可交互门。改名字、改 `ROOMS`/`DOORS` 就成型。

### 第 2 步：写 `index.js`

场景就是一个继承 `SceneBase` 的类，**必须**实现 `build(ctx)`，并声明静态 `meta`。

**最小骨架（多个房间 + 门）：**

```js
import * as THREE from 'three';
import { SceneBase, WorldBuilder } from '../scene-base.js';

// 1) 先把你的世界拆成矩形房间（世界坐标：minX/maxX/minZ/maxZ，单位米）
export const ROOMS = [
  { id: '大厅', minX: -10, maxX: 10, minZ: -12, maxZ: 12 },
  { id: '左屋', minX: -22, maxX: -10, minZ: -6, maxZ: 6 },
];

// 2) 声明房间之间的门洞（wall 是房间的哪面墙，at 是门中心沿墙坐标）
export const DOORS = [
  { room: '左屋', wall: 'e', at: 0, width: 2.2 }, // 左屋东墙对大厅开门
];

export class MyScene extends SceneBase {
  static meta = {
    id: 'my_scene',   // 全项目唯一；场景链靠它互相指向
    name: '我的场景',   // 显示名
    next: null,        // 下一场景 id；null = 最后一个（出口即通关）
    prev: null,        // 上一场景 id；null = 第一个
  };

  build(ctx) {
    const helpers = this.getHelpers(ctx);

    // 1) 所有几何挂 this.root，切场景整组移除
    this.root = new THREE.Group();
    this.root.name = `scene-${this.meta.id}`;
    ctx.scene.add(this.root);

    // 2) 用 WorldBuilder 一把搭出「地面 + 外墙（门洞自动开/门楣自动补）+ 可行走范围」
    const world = new WorldBuilder(this, helpers, {
      rooms: ROOMS, doors: DOORS, height: 4.2,
    });
    world.buildAll();   // 内部：buildFloors + buildOutlineWalls + setLevelBounds

    // 3) 摆家具/装饰（可复用模型）
    helpers.box([1.2, 1, 2], [0, 0.5, -6], { collide: true, occlude: true, tag: 'counter' });

    // 4) 出生点
    this.spawn = { pos: new THREE.Vector3(0, 1.6, 8), yaw: 0 };

    // 5) 敌人 / 拾取物 / 门（见第 3 节）
    // ...
  }
}

export default new MyScene();
```

> ⚠️ **必须 `export default new MyScene()`** —— 导出一个实例，不是类。
> ⚠️ **一个场景只有一个 `index.js` 里的 `ROOMS`/`DOORS` 决定形状**，房间多就多写几行，别怕长。

### 第 3 步：登记到 `registry.js`

```js
// src/scenes/registry.js
import myScene from './my_scene/index.js';
export const SCENES = { floor3, my_scene: myScene };
```

调试：在 `src/main.js` 顶部改 `INITIAL_SCENE`，或 URL `?scene=my_scene` 直接进这个场景。

## 3. 场景里能用到的所有能力

### 3.1 搭空间（房间 + 门）

| 你要的 | 怎么写 |
|---|---|
| 一个矩形房间 | `ROOMS` 里加一项 `{id, minX, maxX, minZ, maxZ}` |
| 两个房间连通 | `DOORS` 里加一项 `{room:'房间id', wall:'e'/'w'/'n'/'s', at:门中心坐标, width:门宽}` |
| 天花高度 | `WorldBuilder` 的 `height`（默认 4.2） |
| 一个方块（家具/墙/机关） | `helpers.box(size, pos, flags)` |

`flags`：`{collide, occlude, noise, tag, id}` 决定它挡不挡路、遮不遮视线、撞了吵不吵。

> **行走范围**：`WorldBuilder.setLevelBounds()` 已经把所有房间矩形的并集交给 `this.bounds`，main 会自动按它限制玩家活动（非矩形也没问题）。你**不用手写边界**。

### 3.2 门（可交互，按 F 推开）

门不只是个洞，可以是个「按 F 过去」的交互物。往 `this.interactables` 推一个对象：

```js
this.interactables.push({
  id: 'door-1', name: '一扇门',
  pos: new THREE.Vector3(x, 1.6, z),  // 玩家靠近这个点附近才提示
  radius: 1.8,                         // 触发半径
  verb: 'F',
  done: false,
  interact() {
    return { kind: 'walkThrough', to: new THREE.Vector3(x2, 1.6, z2), yaw: Math.PI / 2 };
  },
});
```

`interact()` 返回 `{kind:'walkThrough', to, yaw}` 时，main 会让玩家「平滑走过去」（0.45 秒），像真推门。返回其它值或无返回值 = 只触发一次逻辑（开关、对话等）。

> 注意：门洞（`DOORS`）负责「墙上的开口 + 能走过去」，`interactables` 负责「按 F 演出推门过场」。两者可以只用一个：只想能走过去，就只写 `DOORS`；想有推门表演，再加 `interactables`。

### 3.3 敌人（复用 `PatrolEnemy`）

所有「会巡逻/会回头/用视锥发现玩家/会追」的敌人都是同一个 `PatrolEnemy`，只改配置：

```js
import { PatrolEnemy } from '../../reusable/enemy-base.js';

const teacher = new PatrolEnemy(this.root, {
  mat: this.mat,
  home: [0, 0, -10],             // 写板书站位
  patrolPoints: [[3,0,-8],[3,0,8],[-3,0,8],[-3,0,-8]], // 巡逻点（空=站着只回头）
  speed: 1.8, viewDist: 26, viewHalfAngle: 32,
  eyeHeight: 1.75, writeDuration: 45,
  walls: this.walls, occluders: this.occluders, room: this.room,
});
this.npcs.push({ kind: 'teacher', enemy: teacher });
```

想加**新敌人外观**（戴帽子的门卫等）：在 `src/reusable/enemy-base.js` 给 `PatrolEnemy` 加造型分支或派生子类——那属于改可复用层，不是加场景。

### 3.4 拾取物（进物品栏，跨场景携带）

```js
import { makePickup } from '../../reusable/pickup.js';
makePickup(this, { id: 'key_1', name: '钥匙', pos: [0, 1, 0], shape: 'key', radius: 0.6 });
```

- `id` 全项目唯一。物品栏就是一个 id 集合，切场景时**天然随身携带**，不用做任何存取。
- `shape`：`'key'` / `'paper'` / `'cube'`（想加外观→`src/reusable/pickup.js` 的 `SHAPES`）。

### 3.5 出口（切下一个场景 / 通关）

出口是一个触发区 + 目标场景：

```js
this.exits.push({
  id: 'to-next',
  target: 'other_scene',   // 目标场景 id；null = 通关结算
  require: ['key_1'],       // 需要的道具（[] = 不需要）
  hint: '按 E 离开',
  contains(p) { return p.z <= -13; },  // p 是玩家位置(Vector3)，是否在触发区
});
```

**场景链 = 每个场景 `meta.next` / `meta.prev` 的互相指向。** 没有 next 说明是最后一个场景（走到出口就通关）。

> 但**箱庭里的房间之间不需要出口**——房间靠门洞连通，玩家走过去即可。出口只用于「场景 → 另一个场景」这种跨世界切换。

### 3.6 出生点 / 检查点

```js
this.spawn = { pos: new THREE.Vector3(x, 1.6, z), yaw: 0 }; // yaw:0 朝 -Z，π 朝 +Z
this.checkpoint = this.spawn; // 被抓后传回（不设则用 spawn）
```

## 4. 场景独有资源怎么放

只这一场景用的装饰（一张海报、一个讲台、一个特殊机关），两种放法：

**A. 直接用 `helpers.box` 拼**（最常见）：
```js
helpers.box([3, 1, 1], [0, 0.5, -5], { collide: true, occlude: true, tag: 'podium' });
```

**B. 复杂模型写在 `resources.js`**，在 index.js 里 import：
```js
// src/scenes/my_scene/resources.js
import * as THREE from 'three';
export function buildMyStatue(parent, mat) {
  const g = new THREE.Group();
  // ...用盒子和球拼一个雕像
  parent.add(g);
  return g;
}
```

**什么时候该升到全局可复用层？**
同一套模型在**两个及以上场景**都要用 → 挪到 `src/scene/scene-build.js` 的 `PREFABS` 注册成 prefab，用 `placePrefab(this, '名字', {...})` 全局调用。只在一个场景用 → 留在该场景文件夹。

## 5. 调试技巧

- **改初始场景**：`src/main.js` 顶部 `INITIAL_SCENE`，或 URL `?scene=<场景id>`。
- **无头看画面**：`?shot=1` 隐藏开始遮罩，错误显示在左上（`window.__errs` 为空 = 没报错）。
- **自由取景截图**：`?shot=1&eye=x,y,z,yaw[,pitch]`（yaw/pitch 用度），直接把相机摆到指定位置，方便查空间。
- **确认数据对不对**：临时写个 `.mjs`，`import` 场景对象跑一次 `build()`，打印 `bounds.rects.length / walls.length / npcs.length / pickups.length / exits.length / interactables.length`。

## 6. 速查：`SceneBase` 提供的字段

| 字段 | 含义 |
|---|---|
| `this.root` | 本场景几何根节点（切场景整组移除，别把东西加到别处） |
| `this.mat` | 本场景共用的粉笔材质（`getHelpers` 后可用） |
| `this.walls` | 碰撞盒数组（引擎推玩家用） |
| `this.occluders` | 遮挡盒数组（敌人视线用） |
| `this.interactables` | F 键交互物数组（`{id,name,pos,radius,verb,interact,done}`） |
| `this.bounds` | 可行走范围（`WorldBuilder.setLevelBounds` 自动填） |
| `this.npcs` | 敌人 `{kind, enemy}` 数组 |
| `this.pickups` | 可拾取物数组（`makePickup` 自动 push） |
| `this.exits` | 出口数组（`{id,name,target,require,hint,contains}`） |
| `this.spawn` | `{pos: Vector3, yaw}` 出生点 |
| `this.checkpoint` | 被抓回传点（默认同 spawn） |

**除 `build(ctx)` 外都有默认行为，新场景只需填数据。**
